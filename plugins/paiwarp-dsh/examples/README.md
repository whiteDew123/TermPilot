# 示例

示例只是“怎么用 PaiWarp 做一次实测”的说明，不是插件内置脚本。PaiWarp 的核心工具不认识章节、项目或 TermPilot；外层 Agent 读示例和教程，自己决定下一条输入。用户可以只给一篇 Markdown 教程，不先写案例配置文件。

## 一个 Case 写什么

一个 Case 是一段有输入、操作步骤和预期结果的测试案例。建议包含：

- **目标**：这次实测要证明什么。
- **准备**：构建命令、需要的环境变量或目录（不要在文件里写密钥）。
- **步骤**：按顺序写清楚要键入的原文、按键和等待条件。中文提示词保持原话。
- **截点**：哪几个画面值得截图，标签叫什么。
- **核对**：用文件内容、退出码、程序自己的输出逐项核对；不要用“屏幕上出现了成功字样”当唯一证据。
- **教程换图**（可选）：只换哪几个图片地址，原地址是什么，替换方案要先给用户看。

## 目录

- `termpilot/chapter-01.md`：TermPilot 第一期，ReAct 循环，跑起来看看。
- `termpilot/chapter-02.md`：第二期，计划模式和 DAG。
- `termpilot/chapter-03.md`：第三期，短期记忆、上下文压缩和长期记忆。
- `python-cli/case.md`：不使用模型 Key 的普通命令行小项目，用来证明插件不依赖 TermPilot。

`termpilot/` 下的示例会用到当前 TermPilot 仓库、Maven 和本机已有的模型配置。没有这些条件时，照实报告受阻，不要用模拟结果代替真实运行。
